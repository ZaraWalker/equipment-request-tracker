# Request priority

Staff need to identify urgent equipment requests.

- The request form offers Priority choices Low, Normal, and High.
- Normal is selected initially and after submitting a request.
- The selected priority is saved and displayed in the request list, including after refresh.
- Older stored requests without priority remain available and display Normal.
- New requests with no supplied priority default to Normal; unsupported priority values are rejected.
- Preserve required fields, newest-first order, and existing browser storage.
- No filtering, sorting changes, or interface redesign is included.
